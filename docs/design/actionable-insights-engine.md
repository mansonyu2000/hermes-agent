# 从数据到决策 — 可行动的洞察引擎

> 37 张表不是目的。目的是回答一个问题：
> **"基于我对所有人的了解，我下一步该做什么？"**

---

## 一、我们真正想解决的问题

所有数据最终只服务 **五个决策场景**：

```
场景 1: 我该联系谁了？
场景 2: 哪里有赚钱/成长的机会？
场景 3: 谁在拖累我（经济上/情感上/时间上）？
场景 4: 我做出的承诺兑现了吗？
场景 5: 我现在的人生方向对吗？
```

---

## 二、关系分类不是为了分类，是为了决策

之前设计的 13 棵关系分类树（家人/同学/同事/客户/…），真正的价值不是"把好友放进桶里"，而是 **每类关系有不同的处置策略**：

| 关系类型 | 处置策略 | 触发条件 | 行动 |
|---------|---------|---------|------|
| 直系血亲 | **无条件维护** | 超过 7 天没联系 → | 提醒打电话 |
| 核心客户 (A/B) | **每月至少一次价值输出** | 30 天无业务互动 → | 推送行业报告/邀约 |
| 领导/上级 | **关键节点汇报** | 季度末 → | 生成工作总结草稿 |
| 铁哥们/闺蜜 | **情感温度监控** | 亲密度下降 >5 分 → | 提醒约饭 |
| 欠款未还的人 | **催收策略** | 逾期 + 最近有聊天 → | 生成委婉催收话术 |
| 商业机会持有者 | **机会推进** | 上次机会标记后 14 天 → | "上次你说的XX项目怎么样了？" |
| 被我拒绝过的人 | **关系修复评估** | 拒绝后 30 天 → | 判断是否需要主动破冰 |
| 帮过我的人 | **感恩回报** | 帮过我但 90 天我没回报 → | "上次多亏你帮忙，什么时候有空请你吃饭" |

**这才是关系分类的价值：不是标签，是策略。**

## 三、评分不是为了打分，是为了对比

8 维度评分不是装饰。真正有用的是这些对比维度：

### 3.1 找出"不对称关系"

```
不对称类型 1: TA 商业价值高，但我亲密度低
→ 行动: 该维护了，不然机会流失
→ SQL: SELECT * WHERE biz_value > 70 AND closeness < 40

不对称类型 2: 我对 TA 付出多，TA 对我付出少（互惠度低）
→ 行动: 单向关系，重新评估是否继续投入
→ SQL: SELECT * WHERE reciprocity < 35

不对称类型 3: TA 经济信用差（借钱不还），但亲密度高
→ 行动: 情感绑架风险，注意边界
→ SQL: SELECT * WHERE credit_score < 40 AND closeness > 70

不对称类型 4: TA 是我最信任的人，但 90 天没联系了
→ 行动: 最重要的人最容易被忽略
→ SQL: SELECT * WHERE trust > 80 AND last_contact > 90
```

### 3.2 评分趋势 = 提前预警

```
下降趋势 → 提前干预:
  "许国勇的信任度连续 2 个月下降 (85→78→72)"
  → 回溯原因: 我答应他的事没做？还是他对我失信了？
  → 行动: 如果是我的问题，该道歉了

上升趋势 → 顺势推进:
  "张三的商业价值从 40 升到了 65 (TA 刚升职为采购总监)"
  → 行动: 恭喜 + 约见面 + 聊合作可能
```

## 四、拒绝记录不是为了记账，是为了认识自己

### 4.1 拒绝分析告诉你的三件事

**1. 你的边界在哪里？**
```
统计你拒绝最多的类型:
  借钱(18次) → 你对金钱的边界很清晰
  介绍工作(8次) → 你不太愿意用自己的信用背书
  帮忙(3次) → 你很少拒绝帮人 → 边界模糊（风险！）
  
行动: 如果"帮忙"拒绝太少，说明你可能过度付出。
      适当增加对低价值请求的拒绝。
```

**2. 谁的请求你拒绝最多？**
```
张三(8次拒绝) → 这人边界感差，总提不合理请求
→ 行动: 考虑降低关系权重，减少互动频率
```

**3. 哪些拒绝你后悔了？**
```
"后悔拒绝: 王五的项目投资(事后涨了3倍)"
"后悔没拒绝: 李六的借款(果然没还)"

→ 行动: 调整决策模型
  投资类 → 增加数据驱动的评估
  借款类 → 更严格的条件（借条/利息/期限）
```

## 五、机会识别不是为了列表，是为了推进

### 5.1 机会漏斗

```
发现机会 (100%)
  ↓
评估机会 (淘汰 50%)
  ↓
值得跟进 (50%)
  ↓
已采取行动 (20%)
  ↓
成交/完成 (10%)
```

**AI 的职责**：不是简单地"发现机会"，而是追踪这个漏斗，对每一层给出下一步建议。

```
场景:
  2025-01-10: 张三说"我们公司最近在找CRM供应商" → 标记为商业机会
  2025-01-15: 你还未联系张三 → 提醒 + 生成话术
  2025-01-18: 你联系了张三，约了下周三见面 → 更新状态
  2025-01-22: 见面结束，张三说需要内部讨论 → 设置 2 周后跟进
  2025-02-05: 自动提醒："张三的CRM项目该跟进了"
```

## 六、价值观审计不是为了打分，是为了自省

### 6.1 每月一问

```
仁（利他）: 这个月我帮了谁？（多少人次？多少小时？）
  本月: 帮了 5 个人，总计约 12 小时
  上月: 帮了 3 个人，总计约 8 小时
  → 你在变好。但有一个你答应帮但没帮的（王五的简历修改）。

义（公正）: 这个月我做了正确的选择吗？（哪怕不划算）
  本月: 拒绝了供应商的回扣提议
  → 符合你的原则。

信（可靠）: 这个月我答应的事做到了吗？
  本月承诺: 8 个
  已完成: 6 个
  逾期未完成: 2 个（还许国勇的钱、帮李四改代码）
  → 建议立即处理这 2 个逾期的。

礼（得体）: 这个月我在该出现的场合出现了吗？
  本月: 错过了妈妈的生日（该补个电话）
       参加了同事的婚礼（做得对）
  → 补上妈妈的。

智（明智）: 这个月的重大决策经得起复盘吗？
  本月决策: 拒绝了 A 公司的 offer，接受了 B 公司
  暂时无法判断是否正确（1个月后复盘）
```

### 6.2 这不是道德审判

**价值观审计的目的不是给人打分，而是让人自己看到自己的行为模式。** 它不问"你是个好人吗"，它问"你说你想成为什么样的人，你的行为是不是在往那个方向走"。

## 七、把 37 张表压缩成 5 个每日输出

每天早晨，AI 不应该输出 37 张表的报表，而应该只输出 **5 条可行动的信息**：

```
📅 2025-01-16  ·  你的今日洞察

1. 👥 关系紧急
   许国勇的借款 ¥20,000 约定 12 月还，还剩 11 个月。
   但他最近都没找你聊天了（亲密度 ↓ 3 分）。
   建议: 主动撩他一下，不要让他觉得你只在还钱的时候才联系。
   → 已生成话术: "老许，最近咋样？上次你说的学区房看得如何了？"

2. 🔥 机会提醒
   张三（CRM项目）: 上次跟进是 8 天前，该问一下了。
   建议话术: "张总，上次聊的CRM需求你们内部讨论得怎么样？"
   → 这个项目如果成交，预计 ¥50,000-80,000。

3. ⚠️ 逾期警告
   你有 2 件事逾期了:
   · 帮李四改代码（承诺 1月10日，逾期 6 天）
   · 给妈妈打电话（上次通话 23 天前）
   → 建议: 今天午饭时间处理这两件事。

4. 🏥 健康底线
   你连续 8 天没运动了。BMI 26.3（超重）。
   这个月抽烟 ¥720，比上月同期 +12%。
   → 建议: 今晚散步 30 分钟。明天开始每天减少 2 支烟。

5. 🎯 价值观快照
   本月言行一致性: 75%（说了的 8 件事完成了 6 件）。
   强项: 义（拒绝了回扣）、信（最重要的承诺都做到了）
   弱项: 礼（漏了妈妈的生日）、智（1月前的跳槽决策还未复盘）
```

**每天 5 条就够了。不需要更多。**

## 八、如何影响下一步工作/计划

### 8.1 周计划生成

AI 根据本周的 35 条洞察（5×7天），生成下周计划草稿：

```
下周重点 (AI 建议):

1. 人际关系
   - 联系许国勇（关系维护）
   - 推进张三的 CRM 项目（机会）
   - 还王五的人情（互惠）

2. 财务
   - 核对本月消费是否超预算（已用 ¥15,200/¥18,000）
   - 确认李四的 ¥500 代付是否已结清

3. 健康
   - 目标: 运动 3 次（每次 ≥30 分钟）
   - 目标: 抽烟减少到每天 10 支以下

4. 学习
   - 恢复 TypeScript 学习（已停 12 天）
   - 目标: 每天 30 分钟

5. 职业
   - 更新简历（上次更新: 2024 年 6 月）
   - 联系 1 个猎头了解市场行情
```

### 8.2 年度复盘

```
2024 年度关系报告:

你帮助了 47 个人（同比增长 15%）
你被帮助了 23 人（同比持平）
→ 你是净付出型人格（付出/接受比 = 2.04）

你拒绝了 31 个请求:
  · 事后证明是对的: 24 个 (77%)
  · 后悔的: 3 个 (10%)
  · 不确定: 4 个 (13%)
→ 你的判断力在提升（去年后悔率是 18%）

你的关系网络:
  · 新增好友: 156 人
  · 流失/断联: 89 人（超过 180 天未互动）
  · 核心圈（亲密度>80）: 12 人（+2 人）

最强的 3 个关系:
  许国勇: 亲密度 85 · 信任度 88 · 互惠度 72
  于大海: 亲密度 82 · 信用度 95
  老婆:   （你不需要 AI 告诉你她最重要）

最遗憾的 3 件事:
  1. 没有按时还许国勇的钱（延迟了 3 个月）
  2. 没有去参加大学同学的聚会（之后他们再也没叫你了）
  3. 拒绝了一个后来看起来很不错的项目机会

2025 建议:
  1. 减少单向付出（有 8 个人你帮了他们 3 次以上但从未回报）
  2. 把更多的商业机会推进到成交（转化率只有 10%）
  3. 重建 3 段流失的关系（他们曾经很重要）
```

## 九、核心价值主张

**这套系统不是 CRUD，不是展示数据，不是做报表。**

它是：

```
一个不说话的朋友，但它什么都知道。

它知道:
  谁对你好、谁在利用你
  什么机会你该抓住、什么风险你该避开  
  你说过什么但没做、做过什么但忘了复盘
  你在变好还是在变差
  你最该联系的人是谁
  你最该处理的事是什么

它不替你做决定。
它只是帮你看见你自己。
```

## 十、技术实现的最小可行路径

| 优先级 | 输出 | 依赖数据 |
|--------|------|---------|
| **本周** | 好友列表 + 上次联系时间 + 关系分类 | `wechat_friend` + `wechat_friend_relation` |
| **下周** | 关系维护提醒（谁该联系了） | 以上 + 联系间隔计算 |
| **第3周** | 机会提醒（谁说过什么但没跟进） | `friend_opportunity` |
| **第4周** | 逾期警告（承诺/借款/任务） | `personal_unfinished` + `wechat_friend_finance` |
| **第5周** | 每日 5 条洞察 | 以上全部 |
| **第6周** | 周计划生成 | 每日洞察聚合 |
| **第8周** | 月度价值观审计 | `personal_values_audit` |
| **第12周** | 年度复盘报告 | 全部历史数据 |

**每一步都是可用的。不需要等 37 张表建完才有效果。** 从最基础的"该给谁打电话了"开始，逐层往上加智能。
