## 1. 功能概述

在已有单聊基础上，增加群聊能力。一个用户创建群，邀请多个成员，群内消息广播给所有成员。

**与单聊的核心区别**：单聊是 1→1 投递，群聊是 1→N 广播。

---

## 2. 核心场景（用户故事）

### 场景 1：建群并开始聊天

```
Alice 想要和 Bob、Charlie 一起讨论 MIM 架构
  1. Alice 点击"新建群聊"
  2. 输入群名 "MIM 架构讨论"
  3. 从联系人中选择 Bob 和 Charlie
  4. 点击创建
  5. 群出现在 Alice 的联系人列表（群聊分组）
  6. Bob 和 Charlie 的联系人列表也出现这个群
  7. Bob 在群里发 "Hello"，Alice 和 Charlie 都收到
```

### 场景 2：新成员加入

```
Charlie 想拉 Dave 进群
  1. Charlie 打开群信息面板
  2. 点击"邀请成员"
  3. 选择 Dave
  4. Dave 收到群通知，加入成功
  5. Dave 可以看到加入前的历史消息
```

### 场景 3：@all 通知

```
Alice 要通知所有人开会
  1. Alice 在群里输入 "@all 今晚8点开会"
  2. 发送后，Bob、Charlie、Dave 都收到高亮通知
  3. 他们的联系人列表中该群显示 "[有人@我]"
```

### 场景 4：权限控制

```
群的 owner 是 Alice（创建者）
  - Alice 可以邀请/踢人/解散群
  - Alice 可以设置 Bob 为 admin
  - Bob(admin) 可以邀请人，但不能踢 Alice
  - Charlie(member) 只能发消息和邀请人
```

---

## 3. 权限规则（2026-07-20 实施）

群聊采用**来去自由 + 管理员制**：

| 操作 | 谁能做 | 权限校验 |
|------|--------|---------|
| 发消息 | 群成员 | 非群成员 `send_message` 拒绝 |
| 看消息/历史 | 群成员 | 非群成员 `get_history` / `get_group_info` 拒绝 |
| 建群 | 任何人 | 创建者自动成为 owner |
| 邀请人进群 | owner / admin | `invite_members` 校验 owner 或 admin |
| 被邀请进群 | **直接进，无需同意** | `INSERT IGNORE` 幂等 |
| 踢人 | owner / admin | `remove_member` 校验 owner 或 admin |
| 退群 | **任何人，来去自由** | `leave_group` 无权限校验 |
| 改名 | owner / admin | `update_group` 校验 |
| 发公告 | owner / admin | `update_group` 校验 |
| 删公告 | owner / admin | `delete_announcement` 校验 |
| 转让群主 | 仅 owner | `transfer_ownership` 校验，新群主必须是成员 |

**设计原则：**
- 进群不用同意，群是开放的协作空间，不是封闭的私密聊天
- 退群来去自由，不留人
- 踢人需要管理员权限，防止滥用
- 群主可以转让，转让后原群主保留 admin 身份
- 群主退群不解散群，群继续存在

## 4. 功能清单与逻辑关系

```
群聊模块
│
├── 群管理
│   ├── 创建群        ← 选群名 + 选初始成员 → 生成 gid
│   ├── 邀请成员      ← owner/admin 邀请 → 直接进群
│   ├── 踢出成员      ← owner/admin 权限
│   ├── 退出群        ← 任何人来去自由
│   ├── 转让群主      ← owner 转让给群成员
│   ├── 群公告        ← 多条公告，owner/admin 发布/删除
│   └── 群信息查看    ← 成员列表 + 角色 + 加入时间
│
├── 群消息
│   ├── 发送消息      ← 同单聊，目标从 uid 变为 gid
│   ├── 接收消息      ← 订阅 MQTT 群频道
│   ├── 消息历史      ← 按 gid 查询，复用单聊逻辑
│   └── @all 广播     ← 消息标记 → 全员通知
│
├── 群权限
│   ├── 角色体系      ← owner > admin > member
│   ├── 操作鉴权      ← 建群=任何人, 邀请=member+, 踢人=admin+
│   └── 消息权限      ← 只有群成员能收发群消息
│
└── 群列表（前端）
    ├── 群聊分组      ← 联系人列表中独立分区
    ├── 群头像        ← 马赛克拼图（前4成员首字母）
    ├── 未读标记      ← 新消息 → 红点
    └── @提醒         ← 被@ → 橙色标记
```

### 功能依赖关系

```
权限体系（角色定义）
  ├──▶ 创建群 → 邀请成员 → 踢人 → 解散
  │
消息收发（复用单聊 chat 表 + MQTT）
  ├──▶ 群消息发送 → @all 广播
  ├──▶ 群消息接收 → 未读数更新
  └──▶ 消息历史
```

## 5. 数据实体与关系

### 4.1 实体（有哪些"东西"）

| 实体 | 说明 | 对应 |
|------|------|------|
| 群 | 一个聊天组，有群名、群主 | `m_groups` 表 |
| 群成员 | 群和用户的关联，带角色 | `m_group_members` 表 |
| 群消息 | 同单聊消息，多一个群ID标识 | `chat` 表（已有，加 `gid` 列） |

### 4.2 数据字段（每个实体有哪些属性）

**群信息**：
| 字段 | 类型 | 说明 |
|------|------|------|
| gid | 整数 | 群唯一ID（自增） |
| title | 字符串(128) | 群名称 |
| description | 文本 | 群描述（可选） |
| owner_uid | 整数 | 创建者（群主） |
| created_at | 时间 | 创建时间 |
| status | 枚举 | 1=活跃 / 0=解散 |

**群成员**：
| 字段 | 类型 | 说明 |
|------|------|------|
| gid | 整数 | 所属群 |
| uid | 整数 | 成员 |
| role | 枚举 | owner / admin / member |
| joined_at | 时间 | 加入时间 |

**群消息**（改造已有 `chat` 表）：
| 字段 | 类型 | 说明 |
|------|------|------|
| gid | 整数(NULL) | NULL=单聊，非NULL=群聊 |

### 4.3 实体关系

```
users ──┬── m_groups (owner_uid)
        │
        ├── m_group_members (uid, gid)
        │
        └── chat (from_uid)

m_groups ──┬── m_group_members (gid)
           └── chat (gid)
```

一个用户可以创建多个群（owner），加入多个群（member）。
一个群有多条消息，消息通过 `gid` 关联到群。

## 6. 与单聊的关系

群聊不是另起炉灶，是单聊的自然扩展：

| 能力 | 单聊已有 | 群聊复用 | 群聊新增 |
|------|:--:|:--:|:--:|
| 消息存储 | ✅ `chat` 表 | 加 `gid` 列 | — |
| 消息发送 | ✅ MQTT | 改广播模式 | — |
| 消息接收 | ✅ `poll_messages()` | 加 `gid` 过滤 | — |
| 消息历史 | ✅ `get_history()` | 加 `gid` 查询 | — |
| 联系人列表 | ✅ `get_contacts()` | 加群列表 | — |
| 群管理 | — | — | ✅ 新建表 |
| 权限 | — | — | ✅ 角色体系 |
| 前端 UI | ✅ 单聊组件 | 复用消息气泡 | ✅ 群聊特有UI |

## 7. 接口需求

### 6.1 已有接口（可复用）

当前 7 个 `winpeek_mim_*` RPC 中，以下 4 个可扩展支持群聊：

| 接口 | 当前 | 加群聊后 |
|------|------|---------|
| `send` | `{to_uid}` | `{to_uid}` 或 `{gid}`，二选一 |
| `poll` | `{uid}` | `{uid}` 或 `{gid, is_group:true}` |
| `history` | `{uid, peer_uid}` | 加 `{gid}` 模式 |
| `contacts` | 返回用户列表 | 返回用户列表 + 群列表 |

### 6.2 新增接口

| 接口 | 用途 |
|------|------|
| `winpeek_mim_group_create` | 创建群（title + member_uids → gid） |
| `winpeek_mim_group_invite` | 邀请成员（gid + uids） |
| `winpeek_mim_group_info` | 群详情（gid → title + members） |
| `winpeek_mim_group_list` | 我的群列表（uid → groups[]） |

## 8. 非功能需求

| 维度 | 要求 |
|------|------|
| 消息隔离 | 非群成员不能收到群消息、不能查群历史、不能看群信息 |
| 权限校验 | 邀请/踢人/改名/发公告需 owner 或 admin；退群来去自由 |
| 进群规则 | 邀请直接进群，无需被邀请者同意 |
| 历史可见 | 新成员可看到加入前的历史消息 |
| 性能 | 群消息广播应在 1s 内到达所有在线成员 |
| 兼容 | 已有单聊功能不受影响 |
