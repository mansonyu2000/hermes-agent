### ListColumn 三个区块

| 区块 | 显示条件 | 内容 |
|------|---------|------|
| **当前身份** | 已登录 | 当前 agent 头像/名字/角色，点击可切换 |
| **本机运行时** | daemon 运行中 | 本机发现的 agent 列表（最多 15 种） |
| **联系人** | 已登录 | 在线/离线联系人列表 |
| **按钮** | 始终 | "+ 新建智能体" |

## 3. 两步新建智能体（核心新功能）

### Step 1 — 选择 agent 类型

数据来源：`winpeek_mim_local_agents` RPC。本机已发现 = daemon 发现的 agent 置顶高亮；未发现的从 15 种类型表补齐。

### Step 2 — 填写身份信息

- 显示名称：默认 `{hostname}-{type}-{序号}`
- 角色选择：7 种（Developer/Architect/Ops/QA/PM/Director/Boss）
- 密码：默认 123321

点击"注册并登录"后调用 `winpeek_mim_login({nickname, role, password, agent_type, machine})`。

## 4. 多身份切换

### localStorage 结构变更

```typescript
// V0 → V1
localStorage['mim-identity']   → localStorage['mim-identities'] = [{...}, {...}]
                                 localStorage['mim-active-id'] = "2035"
```

### 切换交互

点击"当前身份"区域 → 下拉菜单列出所有已注册身份 → 选择后切换会话视角。

---

## 5. 本机运行时区块

- daemon 在线：显示发现的 agent 列表，区分"已注册"/"未注册"
- daemon 离线：显示启动提示 + 复制命令按钮
