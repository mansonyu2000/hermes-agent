## 4. 数据流架构图

```
用户输入 → API网关 → 身份验证 → 请求路由 → 
    ↓
AI工作流引擎 → [智能路由] → 
    ├── Dify引擎 → 对话管理 → 知识检索 → 大模型 → 响应生成
    └── ComfyUI引擎 → 可视化工作流 → 图像生成 → 响应生成
    ↓
Agent协同系统 → 任务分解 → 专家AI分工 → 结果聚合
    ↓
数据持久化 → 知识库更新 → 向量索引 → 关系数据存储
    ↓
响应输出 → 缓存 → API网关 → 用户端
```
