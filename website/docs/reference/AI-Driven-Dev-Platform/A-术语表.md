# A-术语表

## 技术术语

### AI/ML相关
- **RAGFlow**：检索增强生成工作流系统，用于构建企业级知识库
- **Dify**：AI应用开发平台，支持对话管理和业务逻辑编排
- **ComfyUI**：可视化AI工作流编排工具，主要用于图像生成和处理
- **Agent**：具有自主决策能力的AI智能体，能够执行特定任务
- **LLM (Large Language Model)**：大语言模型，如GPT-4、Claude等
- **RAG (Retrieval-Augmented Generation)**：检索增强生成，结合检索和生成的技术
- **AST (Abstract Syntax Tree)**：抽象语法树，代码的树形表示结构

### 架构相关
- **四层架构**：应用层、编排层、能力层、数据层的系统架构设计
- **微服务**：将应用程序构建为一组小型服务的方法
- **API网关**：统一的API入口，负责路由、认证、限流等功能
- **向量数据库**：专门存储和检索向量数据的数据库，如Qdrant、Milvus

### DevOps相关
- **CI/CD**：持续集成/持续部署，自动化软件交付流程
- **IaC (Infrastructure as Code)**：基础设施即代码，通过代码管理基础设施
- **Kubernetes**：容器编排平台，用于自动化应用程序的部署、扩展和管理
- **Docker**：容器化平台，用于打包应用程序及其依赖项

## 业务术语

### 项目管理
- **MVP (Minimum Viable Product)**：最小可行产品，具有核心功能的产品版本
- **Sprint**：敏捷开发中的迭代周期，通常为2-4周
- **ROI (Return on Investment)**：投资回报率，衡量投资效益的指标
- **里程碑**：项目中的重要节点或阶段性目标

### 效益指标
- **开发效率提升**：通过自动化和智能化手段提高开发速度
- **测试效率提升**：自动化测试和智能测试用例生成提高测试效率
- **知识资产复用率**：已有知识和代码在新项目中的重复使用比例
- **员工培训时间减少**：新员工上手所需时间的缩短程度

## 角色术语

### 技术角色
- **系统架构师**：负责整体技术架构设计和决策
- **AI工程师**：负责AI模型集成和优化
- **DevOps工程师**：负责CI/CD流水线和基础设施管理
- **全栈工程师**：具备前后端开发能力的工程师

### 业务角色
- **产品经理**：负责产品规划和需求管理
- **业务分析师**：负责业务需求分析和转化
- **项目经理**：负责项目计划和执行管理
